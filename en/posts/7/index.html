Windows Docker Installation and Storage Migration

11/10/2023 713 words About 4 min

Docker Desktop is the common GUI client for Docker on Windows, but its installation and storage settings are not very transparent by default.

This post summarizes practical steps to change the Docker Desktop install path, migrate WSL distributions, and move Docker data storage to reduce C drive pressure.

Changing Docker Desktop Installation Directory

First, download Docker Desktop. In fact, the official Docker documentation explains how to manually set its installation directory. However, when searching online, I found that very few sources mention this—I actually stumbled upon it in a reply under a Zhihu post. Many online tutorials suggest "swapping" its installation path by creating symbolic links; I have not tried this method and do not know how reliable it is. The official method, however, works perfectly.

The official approach is to install via the command line. So after downloading the official installer .exe, do not rush to double-click and open it. Open CMD and navigate to the directory where your installer is located. Changing WSL System Directory

Windows places the virtual disk environment for WSL (Windows Subsystem for Linux) on drive C by default. Consequently, Docker's storage directory when using WSL is also located on drive C, typically at: C:\Users\<Username>\AppData\Local\Docker\wsl\data\ext4.vhdx. If it is Docker's WSL directory, you can actually configure it during installation using the command-line parameters mentioned above. If it is already installed, it can still be moved, and this method applies to changing the directory of any WSL subsystem.
